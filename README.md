# StudyConnectTGGateway

Сервер телеграм бота для StudyConnect сервиса. Использует polling опрашивая telegram API раз в какое-то время на поступление новых сообщений.  
Обязательные параметрыт запуска: master.uri (url study connect master) и bot.token (токен полученный в bot father)
